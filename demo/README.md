# 本地模拟试用

需要 Node.js 18 或更新版本。在仓库根目录运行：

```sh
node demo/server.cjs
```

打开 http://127.0.0.1:8876/ ，点击“一键开始”。无需校园 VPN、账号或篡改猴；页面直接加载同一份 `src` 匹配和控制器代码。GM 存储使用本地 localStorage 模拟，题库下载使用六条人工编写数据模拟，**不代表已验证真实 GitHub 下载与篡改猴沙箱**。

第1题单选选项乱序；第2题多选先勾选错误项；第3题图片文件名变化且使用真实 Tesseract 中文 OCR；第4题题库故意有两种不同答案，会暂停；手动选甲、点击下一题并再次开始，可验证第5题只填写而不交卷。手动点击模拟提交后可看到100分。

真实 OCR 首次下载模型需要公网。如果下载失败可展开手动操作并输入题干。通过“重置模拟数据”清除模拟缓存并重新开始。

已用 Edge 浏览器检查：单选乱序、多选替换、真实中文 OCR、冲突暂停、异步连续切题、人工提交。整页 iframe 导航的自动恢复在本地试用中未能稳定连续运行：能填写下一页，但第二次自动导航会停住；需继续调试，不能视为通过。脚本在真实学校页面、真实篡改猴环境尚未验证。
