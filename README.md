# 北邮实验室安全准入考试助手

**BUPT Lab Safety Helper · 北京邮电大学实验室安全教育与考试系统辅助工具**

面向 **北邮实验室安全准入考试、实验室安全教育与考试系统** 的浏览器用户脚本。连接校园网或校园 VPN 后，在本机 Edge / Chrome 中自动下载公开题库，使用中文 OCR 识别题干图片，匹配单选、多选和判断题，并填写当前页选项。

适合希望快速使用北邮实验室安全题库、核对答案和减少重复点击的同学。无需 Python、服务器或 Codex；校园登录与交卷由用户完成。这是社区工具，与学校无官方关联。

| 自动题库 | 本机识别 | 页面填写 | 可控运行 |
| --- | --- | --- | --- |
| 首次下载，后续缓存 | 中文 OCR，手动修正 | 支持选项乱序与多选替换 | 冲突暂停，可随时停止 |

## 快速开始

**[① 安装篡改猴](https://www.tampermonkey.net/)　→　[② 一键安装助手](https://raw.githubusercontent.com/cdd17/bupt-lab-safety-helper/main/bupt-lab-safety-helper.user.js)　→　[③ 打开考试网站](http://10.3.244.16/)**

登录并进入答题页面后，点击右下角 **“一键开始”**。首次自动下载题库并缓存在本机，以后直接使用；遇到不确定题目会暂停，完成后检查并自行交卷。

- 已装篡改猴的用户直接点 **②**，在扩展安装页确认安装。已安装旧版也可点击该链接更新。
- 安装页没有弹出：先确认篡改猴已启用，再按扩展提示开启“允许用户脚本”；仍不生效时，在篡改猴中新建脚本并粘贴本仓库 `.user.js` 文件内容。
- 网站打不开：先连校园网 / VPN。题库和首次 OCR 模型下载还需要公网。
- 看不到助手：确认已进入题目页并启用脚本。安装后已有页面需重新进入或刷新，先保存正在进行的答题。

“一键”指 **一次安装后，在答题页点一次开始**。首次安装扩展、确认安装和校园登录仍由用户完成。

> **当前版本：0.2.0 原型。** 19项匹配与加载测试通过，本地 Edge 模拟验证了识别和填写主体。整页 iframe 连续翻页仍不稳定，真实篡改猴环境及校园页面尚未验收。请先模拟试用，再在练习页面验证。

## 模拟试用

安装 Node.js 18 或更新版本后，下载仓库并在根目录运行：

```sh
node demo/server.cjs
```

打开 **[本机模拟页](http://127.0.0.1:8876/)**，点“一键开始”。无需 VPN、校园账号或篡改猴。模拟题库下载和存储接口，使用同一份控制器源码及真实中文 OCR。详见 [模拟说明](demo/README.md)。

已在 Edge 验证单选乱序、多选替换、中文 OCR、答案冲突暂停、停止下载、异步切题与人工交卷。整页 iframe 导航仍存在连续跳转停顿，真实篡改猴沙箱和原题库公网下载尚未验收。

## 使用

1. 在 Edge 或 Chrome 中安装官方扩展商店的 **Tampermonkey（篡改猴）**。它与用于连接 Codex 的浏览器扩展是两个不同的扩展。
2. 如扩展提示，按照 Tampermonkey 的说明启用浏览器“允许用户脚本”设置。
3. 点击顶部“一键安装助手”，在扩展安装页确认安装。
4. 连接校园网或 VPN，手动登录 `http://10.3.244.16/` 并进入答题页面。右下角应显示助手。
5. 点击“一键开始”，题库为空时自动从 [KY-zhang-X/bupt-lab-safety](https://github.com/KY-zhang-X/bupt-lab-safety/tree/main/data) 下载 14 个公开 JSON 文件并缓存。下载全部成功后才替换缓存，失败时保留原题库。
6. 如需手动操作，展开“手动操作与题库”，可以更新题库、导入 JSON、识别和填写当前题。一次选择多个 JSON 文件导入，导入操作会替换已有题库。
7. 不可靠匹配、OCR 近似匹配、网络异常会暂停。OCR 文本可以手动修正后重新识别。所有题目完成后，检查页面上的漏答提示，再自行点击网站的提交按钮。

脚本仅匹配该内网 IP 的页面。不会代替登录，也不会配置或绕过 VPN。打开答题页面后才会显示助手；安装后已有页面需要重新进入或刷新，注意先保存正在进行的答题。

## 识别与填写流程

已观察到该考试系统的题干通过图片展示，图片文件名也可能与旧题库不同。HTML 可以读出选项和题目图片地址，但未必包含题干文字。判断题只有“对 / 错”两个相同选项，不能用选项区分题目。

匹配流程：

| 步骤 | 处理方式 |
| --- | --- |
| ① 准备题库 | 下载公开题库并缓存在本机 |
| ② 读取当前题 | 获取页面选项和题干图片，必要时执行本机中文 OCR |
| ③ 匹配与核对 | 对照题库；不确定时暂停，等待人工核对 |
| ④ 填写与继续 | 按当前选项内容填写，再进入下一题；最后由用户检查并交卷 |

- 题干完全匹配、本机确认过的图片映射、题库原始图片文件名匹配。
- 题干图片无法直接匹配时，使用 Tesseract.js 在本机 OCR。
- 高相似度 OCR 结果需要人工核对；确认后缓存该图片与题干的映射。
- 至少三个不同选项时，可以用完整选项集合匹配。多个候选只有答案一致才能填写；已有题干不一致时不使用该回退。
- 选项可能被打乱，因此按选项内容映射到当前页字母，不直接照抄题库中的字母。

题库答案可能有误，旧题库也不保证覆盖新题。脚本不会保证分数。

## 本机 OCR 与数据

OCR 使用固定版本 Tesseract.js 5.1.1。Tampermonkey 会从 jsDelivr 下载库文件，Tesseract 首次运行会下载 worker、WASM 和中文/英文模型；需要可访问公网。推理在浏览器本机执行，代码没有将题干、答案或考试截图上传到外部服务的接口。

浏览器的 CSP、用户脚本隔离环境或校园网络可能影响 OCR 加载。失败时助手会暂停，可以手动输入完整题干继续。当前版本没有打包完整离线 OCR 资源。

导入题库、确认后的图片映射、最近 500 条操作记录保存在 Tampermonkey 本地存储。代码不读取用户名、密码或 Cookie。可导出操作记录或清除本机数据。关闭页面前建议点击“停止”，以免下次进入答题页面时恢复连续填写。

自动下载只访问原题库仓库的公开 JSON 文件，使用匿名请求，不发送网站会话。新增的 `GM_xmlhttpRequest` 权限仅允许题库域名 `raw.githubusercontent.com`。不在本仓库重新打包第三方题库。原题库使用 main 分支，文件列表或格式变化可能导致下载失败；可手动导入作为备用方式。

## 题库格式

兼容原项目 `data/*.json` 的数组结构，例如以下人工编写的格式样例：

```json
[
  {
    "qtext": "题干：示例题干",
    "qurl": "\\upload\\theme_picture\\example.jpeg",
    "qtype": "单选题",
    "opts": {"A": "示例选项一", "B": "示例选项二"},
    "ans": ["A"]
  }
]
```

本仓库只包含工具代码和人工编写的测试样例，不包含第三方题库、考试截图、身份信息或会话数据。题库项目的许可和学校对工具使用的要求由使用者自行确认。

## 常见问题

**这是北邮实验室安全准入考试题库吗？** 工具自动下载 [原题库仓库](https://github.com/KY-zhang-X/bupt-lab-safety)，本仓库负责识别和填写，不重新分发题库。旧题库不保证覆盖新题或答案准确。

**能保证满分或无人值守吗？** 不能。OCR 近似匹配、答案冲突会暂停，整页 iframe 自动翻页仍需修复。模拟100分包含人工处理冲突题，不代表正式考试效果。

**和 Codex 浏览器扩展一样吗？** 不一样。实际安装需要 Tampermonkey（篡改猴）；本地模拟页无需扩展。

**为什么没有出现助手？** 确认脚本已启用、浏览器允许用户脚本且已进入题目页，先保存作答再刷新。仅登录首页不会显示填写助手。

## 开发

需要 Node.js 18 或更高版本，无 npm 安装依赖。

```sh
node --test test/*.test.cjs
node build.cjs
node --check bupt-lab-safety-helper.user.js
```

- `src/matcher.js`：纯匹配逻辑，独立于网页。
- `src/controller.js`：DOM 适配、OCR、填写与暂停控制。
- `src/loader.js`：公开题库下载、验证和去重。
- `build.cjs`：生成可安装用户脚本。

## 手动验收清单

优先在练习页面验证，不要为了测试重复提交正式考试。

- 单选、多选、判断题的选中状态正确；已勾选的多选能完整替换。
- 图片文件名变化时，判断题可通过 OCR 或手动题干识别。
- 答案冲突与近似 OCR 会暂停，不自动跳过。
- 连续填写在完整 iframe 导航与同页面异步切题时均可继续；停止后不再点击下一题。
- 最后一题只填写并提示人工交卷。
- 网络断开、OCR 下载失败、页面变化时显示暂停原因。
