# BUPT Lab Safety Helper

在连接校园网或校园 VPN 的本机 Edge / Chrome 中，用导入的题库识别实验室安全考试题目并填写选项。

**状态：0.1.0 原型。** 匹配逻辑有自动化测试；尚未在真实考试中安装并验证此脚本。此前浏览器人工辅助答题的成功，不代表本脚本已经通过端到端验证。

## 使用

1. 在 Edge 或 Chrome 中安装官方扩展商店的 **Tampermonkey（篡改猴）**。它与用于连接 Codex 的浏览器扩展是两个不同的扩展。
2. 如扩展提示，按照 Tampermonkey 的说明启用浏览器“允许用户脚本”设置。
3. 在 Tampermonkey 中新建脚本，将本仓库 `bupt-lab-safety-helper.user.js` 的全部内容粘贴进去并保存。
4. 连接校园网或 VPN，手动登录 `http://10.3.244.16/` 并进入答题页面。右下角应显示助手。
5. 从 [KY-zhang-X/bupt-lab-safety](https://github.com/KY-zhang-X/bupt-lab-safety/tree/main/data) 下载需要的 JSON 题库。一次选择多个文件导入，导入操作会替换已有题库。
6. 点击“识别当前题”，检查匹配题干和答案，再点击“填写当前题”；也可点击“连续填写”。
7. 不可靠匹配、OCR 近似匹配、网络异常会暂停。OCR 文本可以手动修正后重新识别。所有题目完成后，检查页面上的漏答提示，再自行点击网站的提交按钮。

脚本仅匹配该内网 IP 的页面。不会代替登录，也不会配置或绕过 VPN。打开答题页面后才会显示助手；安装后已有页面需要重新进入或刷新，注意先保存正在进行的答题。

## 为什么不是只解析源代码

已观察到该考试系统的题干通过图片展示，图片文件名也可能与旧题库不同。HTML 可以读出选项和题目图片地址，但未必包含题干文字。判断题只有“对 / 错”两个相同选项，不能用选项区分题目。

匹配流程：

- 题干完全匹配、本机确认过的图片映射、题库原始图片文件名匹配。
- 题干图片无法直接匹配时，使用 Tesseract.js 在本机 OCR。
- 高相似度 OCR 结果需要人工核对；确认后缓存该图片与题干的映射。
- 至少三个不同选项时，可以用完整选项集合匹配。多个候选只有答案一致才能填写；已有题干不一致时不使用该回退。
- 选项可能被打乱，因此按选项内容映射到当前页字母，不直接照抄题库中的字母。

题库答案可能有误，旧题库也不保证覆盖新题。脚本不会保证分数。

## 本机 OCR 与数据

OCR 使用固定版本 Tesseract.js 5.1.1。Tampermonkey 会从 jsDelivr 下载库文件，Tesseract 首次运行会下载 worker、WASM 和中文/英文模型；需要可访问公网。推理在浏览器本机执行，代码没有将题干、答案或考试截图上传到外部服务的接口。

浏览器的 CSP、用户脚本隔离环境或校园网络可能影响 OCR 加载。失败时助手会暂停，可以手动输入完整题干继续。当前版本没有打包完整离线 OCR 资源。

导入题库、确认后的图片映射、最近 500 条操作记录保存在 Tampermonkey 本地存储。代码不读取用户名、密码或 Cookie。可导出操作记录或清除本机数据。关闭页面前建议点击“停止”，以免下次进入答题页面时恢复连续填写。

## 题库格式

兼容原项目 `data/*.json` 的数组结构，例如以下人工编写的格式样例：

```json
[
  {
    "qtext": "题干：示例题干",
    "qurl": "\\upload\\theme_picture\\example.jpeg",
    "qtype": "单选题",
    "opts": {"A": "示例选项一", "B": "示例选项二"},
    "ans": ["A"]
  }
]
```

本仓库只包含工具代码和人工编写的测试样例，不包含第三方题库、考试截图、身份信息或会话数据。题库项目的许可和学校对工具使用的要求由使用者自行确认。

## 开发

需要 Node.js 18 或更高版本，无 npm 安装依赖。

```sh
node --test test/*.test.cjs
node build.cjs
node --check bupt-lab-safety-helper.user.js
```

- `src/matcher.js`：纯匹配逻辑，独立于网页。
- `src/controller.js`：DOM 适配、OCR、填写与暂停控制。
- `build.cjs`：生成可安装用户脚本。

## 手动验收清单

优先在练习页面验证，不要为了测试重复提交正式考试。

- 单选、多选、判断题的选中状态正确；已勾选的多选能完整替换。
- 图片文件名变化时，判断题可通过 OCR 或手动题干识别。
- 答案冲突与近似 OCR 会暂停，不自动跳过。
- 连续填写在完整 iframe 导航与同页面异步切题时均可继续；停止后不再点击下一题。
- 最后一题只填写并提示人工交卷。
- 网络断开、OCR 下载失败、页面变化时显示暂停原因。
